## Asset rules

- Avoid giant hero images that dominate the UI.
- Prefer clear square product images for product cards.
- Use object-fit: cover for crops.
- Use object-fit: contain for electronics.
- Always include alt text.
- Add lazy loading.
- Provide fallback image.

## Attribution

Create:
`assets/images/ATTRIBUTIONS.md`

Each row:
- filename
- source
- author/provider
- license
- source URL

If license cannot be determined confidently, prefer another source.
