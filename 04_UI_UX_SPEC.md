# UI/UX SPEC HYCANE

## Visual identity

Mood:
- fresh
- modern
- credible
- sustainable
- smart
- approachable

Palette guidance:
- deep green for plant/sustainability
- blue for technology/data
- neutral gray for surfaces
- amber/yellow for warnings
- red only for critical

## Typography hierarchy

- Display: 28-36 px
- Page title: 24-30 px
- Card title: 16-18 px
- Body: 14-16 px
- Caption: 12-13 px

## Dashboard cards

Large metric:
`6,24`

Label:
`pH air`

Support:
`Normal · target 5,8–6,8`

Action:
`Lihat detail`

## Navigation labels

- Dasbor
- Monitoring
- Rekomendasi AI
- Tanaman Saya
- Marketplace
- Edukasi
- Komunitas
- Pesanan
- Notifikasi
- Profil
- Pengaturan

## Empty state style

Friendly, informative, never blank.

Example:
“Belum ada pesanan. Mulai dari kit pemula atau refill yang kamu butuhkan.”

## Recommendation card

Elements:
- severity dot
- issue title
- simple explanation
- action button
- tutorial link

## Marketplace card

Elements:
- image
- badge
- name
- one-line beginner explanation
- price
- stock
- add to cart

## Accessibility

Do not rely on color alone.
Use text labels such as:
Normal, Perhatian, Mendesak.
