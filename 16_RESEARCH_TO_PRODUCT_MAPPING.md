# RESEARCH TO PRODUCT MAPPING

| Consumer insight | Product implication | UI implication |
|---|---|---|
| Plants becoming unhealthy/dead is the top problem | Focus on outcome and troubleshooting | Dashboard health + actionable alert |
| Beginner is dominant | Beginner-first UX | Plain language, guided steps |
| Tutorials are the strongest explicit demand | Education is a core feature | Learn cards + contextual tutorials |
| Community demand is strong | Community should be visible | Discussions + Q&A |
| pH and TDS/EC are explicitly requested | Keep these as primary sensors | Large metric cards + charts |
| Diagnosis is requested | Recommendation needs “what to do now” | AI page |
| Price/DIY is a serious barrier | Marketplace must show transparent prices | Benchmark + demo retail |
| Sustainability is rarely a buying driver | Do not over-index on green messaging | Sustainability in product/education, not main CTA |
| Bagasse is rarely a customer request | Treat it as differentiation, not demand evidence | “Why bagasse?” explainer |
| Subscription/app lock-in creates friction | Keep core operation usable without subscription | Free core, premium optional |
| Passive systems are alternatives | Respect DIY/Kratky in education | Comparison lesson |
