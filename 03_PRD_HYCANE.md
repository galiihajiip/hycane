# PRD HYCANE DEMO APP

## 1. Product goal

Membangun demo web app HYCANE untuk menunjukkan bagaimana smart hydroponic ecosystem bekerja dari sudut pandang pengguna pemula.

## 2. Primary user

Pemula hidroponik yang:
- ingin mulai bertanam
- bingung membaca parameter air
- takut tanaman mati
- membutuhkan tutorial sederhana
- sensitif terhadap harga

## 3. Core user journey

Login
→ Dashboard
→ lihat kondisi
→ menemukan issue
→ membaca recommendation
→ menjalankan action
→ bila perlu membeli item
→ belajar melalui education
→ kembali monitor

## 4. Key pages

| Page | Role |
|---|---|
| Login | masuk demo |
| Dashboard | ringkasan kesehatan sistem |
| Monitoring | grafik real-time |
| AI Recommendation | tindakan yang perlu dilakukan |
| My Crops | kondisi tanaman |
| Marketplace | kit, refill, spare part |
| Education | belajar dari nol |
| Community | diskusi |
| Orders | status transaksi |
| Notifications | peringatan |
| Profile | identitas dan histori |
| Settings | preferensi + demo controls |

## 5. Success criteria

User dapat menjawab 4 pertanyaan dalam <30 detik:
1. Apa kondisi sistem saya?
2. Apakah ada masalah?
3. Saya harus melakukan apa?
4. Kalau butuh barang, saya bisa beli di mana?

## 6. Demo moments

Moment 1:
Normal system.

Moment 2:
pH turun.

Moment 3:
AI recommendation muncul.

Moment 4:
User membuka tutorial.

Moment 5:
User membeli refill / spare part.

Moment 6:
Dashboard kembali normal.

## 7. Non-goals

Bukan:
- e-commerce production
- payment gateway nyata
- predictive ML production model
- IoT backend production
- user management production

## 8. Product principle

Jangan membuat user belajar teknologi untuk menggunakan produk.
Produk yang harus “menerjemahkan teknologi” untuk user.
